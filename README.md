# Todo_List

## Overview
- This is where you can create a to-do list.
- The entered Todos are saved locally.

## How to use
- Install the VS Code extension: Live Server.

Execute the following command in the VS Code terminal to clone it.

Right-click Todo_List.html and select "Open with Live Server".

Enter a Todo in the input field and press Enter or click "Add Todo". The Todo you entered will be added to the central area.

If you click the checkbox to the left of a Todo, a line will be drawn through the Todo and it will be marked as completed.

Click the trash can to the right of a todo to delete it.

Clicking the CLEAR ALL button on the top right of the screen will display a confirmation screen asking if you want to delete all Todos. If you confirm, all Todos will be deleted.
